## Journey rules

- core Marrero journeys stay on the new first-party site
- external destinations are used only where an external provider is actually part of the workflow
- Medicare.gov remains an official external education resource
- Power Play Radio remains the external podcast destination
- the existing Jotform remains the current external application/enrollment form
