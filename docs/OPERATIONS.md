# OPERATIONS

Operational ownership requires:
- one canonical production implementation
- current `docs/STATUS.md`
- passing `npm run verify`
- CI on main/PRs
- verified Vercel production state for releases
- documented ADRs for architectural changes
- documented repeatable failures
- no silent external dependencies or visual override files

The repository is operational memory, not a documentation archive. Stale statements must be corrected when implementation reality changes.
