# RUNBOOK

## Session start
1. Read onboarding order in `AGENTS.md`.
2. Confirm `docs/STATUS.md` matches repository reality.
3. Run available checks and capture evidence.

## If blocked
Record:
- exact blocker
- completed work
- next required human/system action
- parallel non-blocked actions executed

## Release checklist (minimum)
- implementation complete for scoped change
- verification evidence captured
- security review performed
- docs updated (`STATUS`, `DECISIONS`, impacted specs)
