# ARCHITECTURE

## Current state (audited)
This repository snapshot contains documentation baseline only and does not currently include runtime website source code.

## Target architecture expectations
When implementation is present, architecture should provide:
- clear page/route structure by audience journey
- reusable design-system primitives for depth/material/typography
- isolated conversion workflow modules (forms/scheduling/contact)
- measurable test layers (unit/component/e2e smoke)
- deterministic deployment pipeline with preview + production distinction

## Immediate architecture risks
- No runnable code to verify current behavior
- No build/test/deploy contract in repository
- No automated guardrails against regressions
