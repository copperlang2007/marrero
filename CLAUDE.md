# CLAUDE.md

This repository uses **AGENTS.md as the canonical operating contract** for all coding agents.

To avoid drift, follow `AGENTS.md` for process, constraints, definition of done, evidence requirements, and update obligations.

Required read order:
1. `AGENTS.md`
2. `docs/STATUS.md`
3. `docs/PRODUCT_CONTRACT.md`
4. `docs/ARCHITECTURE.md`
5. relevant ADRs
6. implementation files
7. recent QA/test evidence
